# Changelog

All notable changes to this project will be documented in this file.

## [1.0.0] - 2026-04-07

### Added

- Initial public release
- `SKILL.md` with frontmatter, MCP routing rules, and common interaction patterns
- Support for `teslamate` (read) and `tesla_fleet_api` (commands) MCP servers
- GitHub Actions workflow for automated zip release on every push to main
- GitHub Actions workflow for SKILL.md and marketplace.json validation
- `references/` directory with vehicle commands, energy systems, and TeslaMate query docs
- `.claude-plugin/marketplace.json` for Claude marketplace metadata
- Apache 2.0 license
